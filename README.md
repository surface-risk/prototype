# Surface Risk prototype

Prototype for discovery conversations with potential buyers. It has two parts:

| Folder | What it is |
| --- | --- |
| `engine/` | Python scoring engine, a port of the v0.5 workbook (`Calc` and `Scored`). Its tests reproduce the workbook's sample-firm results to within 0.01 and run the synthetic engine tests (null, High-wire, Fortress firms). See `engine/README.md` and `engine/NOTES.md`. |
| `web/` | Single-file website and clickable app: home, how it works, Founding Members, register interest, administrator set-up, staff / management survey and the sample report. |

**Everything is fictional.** The firm, people, answers, check results and peer scores are simulated. Country-risk values are illustrative, not real index scores. The register-interest form does not send or store anything.

## Run it

```bash
# Engine
cd engine && python -m surface_risk_engine sample && python -m pytest -q tests

# Rebuild the web data and page after changing the engine or methodology
python -m surface_risk_engine export            # writes web/data/sample_report.json, engine_tests.json
cd .. && python web/tools/build.py              # writes web/dist/index.html and web/dist/artifact.html
```

Open `web/dist/index.html` in a browser; it works offline except for web fonts. `web/dist/artifact.html` is the same page without the document wrapper, for publishing as a claude.ai Artifact.

`web/tools/build_ui_content.py <workbook.xlsx>` regenerates `web/data/ui_content.json` (survey text, area descriptions) from the methodology config and the workbook. The workbook itself is not in this repository.

## Web structure

| Path | What it is |
| --- | --- |
| `web/src/page.css` | Styles and brand tokens; dark-first with a light theme |
| `web/src/app-core.js` | Router, shared charts and the website pages |
| `web/src/app-report.js` | Sample report: indices, matrix / loss-tilt switch, area scores, priorities, departments (level switch), checks, exposure, leadership |
| `web/src/app-demo.js` | Administrator set-up wizard (live weights and exposure preview, reporting groups with roll-up) and the survey |
| `web/brand/` | Logo mark and lockup (SVG) |
| `web/data/` | JSON generated by the engine and the build tools |

## Decisions reflected

- **Website wording:**
  - Public pages call the product a benchmarked diagnostic. They make no predictive claims and show no testimonials.
  - The ORX taxonomy is mentioned only as "subject to permission".
- **Department reporting level:** set by headcount: fewer than 30 staff gives 2 groups, 30 to 150 gives 4, more than 150 gives 8. Groups below 5 respondents merge with a sibling, and every firm can roll up to 2 groups.
- **Phishing simulation:** included, run by a partner.
- **Matrix or loss tilt:** still undecided, so the report has a switch between the two views. The engine tests show the loss tilt separates the patterned firms while staying near zero for random answers.
